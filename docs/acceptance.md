### M7-7 点不动（2026-10-07 补，owner 报告后定位）

**症状**：阅读页里所有课文都点不开，因此看不到原文、没有播放、没有语音；
单词页的 ▶ 与「删」也点不动。

**根因**：`jid()`（M2-1 为了给字符串 id 加引号引入）产出的是 `JSON.stringify`
的结果 —— 带**双引号**的 `"L01"`，却被插进**双引号属性** `onclick="openL(${jid(id)})"`，
于是属性被提前截断，浏览器只拿到 `onclick="openL("`。点下去不报错、没反应。

**为什么一直没被发现**：这是**基线 commit `39d283f` 就有的** bug，不是 M7 引入的。
而 `tools/test_render.mjs` 早期版本是**直接调用** `openL('L01')` 来断言课文页的，
**绕过了「点卡片」这条用户路径** —— 所以 37 项全绿，线上却点不动。

**修复**：`jid = id => JSON.stringify(String(id)).replace(/"/g, '&quot;')`（一处，修好全部三个调用点）。

**测试补强**（这才是关键）：
1. 新增「真实点按」场景：`document.querySelector('#read .card').click()`，不调内部函数；
2. 新增「全站 onclick 语法校验」：遍历每个 tab 上所有 `[onclick]`，
   逐条 `new Function(src)` 试语法 —— 引号截断的处理器会在这里现形；
3. 单词页「删」按钮真点一次，断言词真的没了。

教训已写进本文件顶部：**凡是用户用手点的，测试也必须用手点。**

### M7-8 生词区 ▶ 点不动（2026-10-07 补，owner 第二次报告）

**症状**：课文能读了，但下面生词表的 ▶ 按下去没声音。

**根因**：`onclick="event.stopPropagation();playWord({pt:'',a:curL.wa&&curL.wa[i]})"` ——
`i` 是 `map((w, i) => …)` 的**渲染期变量**，没有被插值进字符串。浏览器里点的时候
`i` 根本不存在 → `ReferenceError: i is not defined`，按钮静默失效。

**修法**：不再把数据塞进属性，只传下标：`playLW(${i})`，由函数自己取词与音频。

**为什么第一次没抓到**：`jid()` 那个 bug 修完后，我只验证了「点课文卡片」这条路径，
没有逐个点课文页里的其它按钮。同类问题（handler 里引用渲染期变量）当时没有覆盖。

**测试补强（第二次补强）**：
1. 场景 12：生词 ▶ / ＋ / 全部加入，**各自在干净状态上真点一次**并断言效果；
2. 场景 13：**全站交互扫描** —— 每个 tab（含跟读/听写模式、错词筛选）上所有带
   `onclick` 的元素全部点一遍，断言 CDP 没有 `Runtime.exceptionThrown`
   （事件处理函数里抛的异常不会让 `click()` 抛，只会变成未捕获异常）。

**顺带删掉一条不可靠的检查**：原先想用「静态扫 onclick 引用的标识符在不在全局」
来提前发现这类问题，但它**两次给出假绿**（DOM 快照时机不对 + 页面里嵌套 `(0,eval)`
结论不可靠）。假绿的检查比没有更糟，因此删除，改用上面的真实点按。
